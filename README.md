# HAUNT//HOUND

Bolt together a cursed mech, hunt through haunted static, and trust your ears, because half the pings on your radar are ghosts.

A browser squad-tactics mech game with a haunted CRT cockpit UI. Built with Kiro for Kiroween 2026 (Costume Contest).

Status: kickoff (10/30/2026). Specs and steering live in `.kiro/`.
